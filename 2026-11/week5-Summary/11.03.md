# 11-03 

## 今天学了/做了什么

-11.02:在学SQL的函数，字符串函数：concat(x,y)：把字符串拼接起来。lower,upper就是把字符串全部大/小写.lpad(str,n,'x'):左填充，用字符串x在左边把str填充到n个字符串长度。rpad就是填充到右边。trim（str）把字符串左右两边的空格删掉。substring(str,start,len):最终结果是字符串str从start起往后len个长度。
数值函数:ceil(x):向上取整。floor(x):向下取整。mod(x,y):返回x/y的模。rand()：生成0-1之间的随机数。round(x,y)：返回x四舍五入的值，保留y位小数。
日期函数:curdate():当前日期。curtime():当前时间。now():日期和时间。year(date):年份。month(date):月份。day(date):日期。date_add(date,intherval 16 day):返回当前时间增加16天后的时间。datadiff(date1,date2):返回1和2之间的天数。
流程函数:感觉比较重要的是那个 case when [val1] then [res1] ... else[default] END:如果val1为true返回res1，否则返回default; if(value,t,f):如果value为true则返回t，否则返回f；ifnull(value1，value2)：如果value1不为空，则返回value1，否则返回value2，我感觉可能是防止出bug的作用。

create table score(
    id int comment  'ID',
    name varchar(20) comment'姓名',
    math int comment'数学成绩',
    english int comment'英语成绩',
    chinese int comment'语文成绩'
)comment '成绩表';
insert into score (id, name, math, english, chinese)
values
    (1, 'Tom', 67, 88, 95),
    (2, 'Rose', 23, 66, 90),
    (3, 'Jack', 56, 98, 76);

select name,
       case  when math>='85' then '优秀' when math>='60' then '及格' else '不及格' end as '数学成绩',
       case  when english>='85' then '优秀' when english>='60' then '及格' else '不及格' end as '英语成绩',
       case  when chinese>='85' then '优秀' when chinese>='60' then '及格' else '不及格' end as '语文成绩'
from score;
