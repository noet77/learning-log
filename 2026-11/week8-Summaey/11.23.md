## 1. JS 的引入方式

| 方式 | 写法 | 说明 |
| --- | --- | --- |
| **内部脚本** | `<script> ... </script>` | 将 JS 代码直接定义在 HTML 页面中，通常放在 `<body>` 的底部 |
| **外部脚本** | `<script src=""></script>` | 将 JS 代码单独定义在 `.js` 文件中，通过 `src` 属性引入 |

## 2. JS 的书写规范

- **结束符**：每行语句以分号 `;` 结尾，结尾分号可有可无。

## 3. 变量与常量

- **特点**：JS 是**弱类型语言**，变量可以存放不同类型的值。

| 关键字 | 作用 | 说明 |
| --- | --- | --- |
| `let` | 声明变量 | 值可以被修改 |
| `const` | 声明常量 | 一旦声明，常量的值不能改变 |
| `var` | 声明变量（早期写法） | 并不严谨，**不推荐使用** |

## 4. 输出语句

| 语句 | 作用 | 使用频次 |
| --- | --- | --- |
| `alert()` | 弹出警告框 | 较高 |
| `console.log()` | 写入浏览器控制台 | 较高 |
| `document.write()` | 向 HTML 的 `body` 内输出内容 | — |

## 5. 数据类型

JavaScript 的数据类型分为：**基本数据类型** 和 **引用数据类型（对象）**。

### 5.1 基本数据类型

| 类型 | 说明 |
| --- | --- |
| `number` | 数字（整数、小数、`NaN`（Not a Number）） |
| `boolean` | 布尔值，只有 `true`、`false` |
| `null` | 对象为空。JS 是**大小写敏感**的，因此 `null`、`Null`、`NULL` 是完全不同的 |
| `undefined` | 当声明的变量未初始化时，该变量的默认值是 `undefined` |
| `string` | 字符串，单引号、双引号、反引号皆可，**推荐使用单引号** |

### 5.2 模板字符串与反引号

反引号可以简化字符串的拼接：

```javascript
console.log('我是' + name + ', 我今年' + age + '岁');
console.log(`我是${name}, 我今年${age}岁`);
```

## 6. 函数

### 6.1 三种定义方式

**方式一：函数声明**

```javascript
function add(a, b) {
    return a + b;
}
let result = add(1, 2);
console.log(result);
```

**方式二：函数表达式**

```javascript
let add = function (a, b) {
    return a + b;
};
let result = add(1, 2);
console.log(result);
```

**方式三：箭头函数**

```javascript
let add = (a, b) => {
    return a + b;
};
let result = add(1, 2);
console.log(result);
```

### 6.2 注意

JS 是**弱类型语言**，定义函数时，**形参、返回值都无需指定类型**。

## 7. 对象

```javascript
let user = {
    name: 'Tom',
    age: 20,
    gender: '男',
    sing() {
        alert(name + '唱着最炫的民族风');
    }
};
console.log(user.name);
user.sing();
```

## 8. JSON

### 8.1 概念

- **JSON**：JavaScript Object Notation，JavaScript 对象标记法（JS 对象标记法书写的文本）。
- 由于其**语法简单、层次结构鲜明**，现多用于作为数据载体，在网络中进行数据传输。

### 8.2 JS 对象 vs JSON 文本

**JS 对象**

```javascript
{
    name: "Tom",
    age: 20,
    gender: "男"
}
```

**JSON 文本**

```json
{
    "name": "Tom",
    "age": 20,
    "gender": "男"
}
```

### 8.3 两者之间的转换

| 方向 | 方法 | 说明 |
| --- | --- | --- |
| JSON 文本 → JS 对象 | `JSON.parse(...)` | 将 JSON 文本解析为 JS 对象 |
| JS 对象 → JSON 文本 | `JSON.stringify(...)` | 将 JS 对象转换为 JSON 文本 |

### 8.4 常见问题

1. **JSON 格式有什么特点？**
   - JSON 格式的文本中，所有的 key 必须使用**双引号**引起来。
2. **JSON 对象的两个方法？**
   - `JSON.parse`：将 JSON 字符串转为 JS 对象。
   - `JSON.stringify`：将 JS 对象转为 JSON 字符串。

## 9. DOM

1. **什么是 DOM？**
   - **文档对象模型**，JS 提供的专门用来操作网页内容的对象。
2. **如何获取 DOM 对象？**
   - `document.querySelector('选择器')`
   - `document.querySelectorAll('选择器')`

## 10. 事件

### 10.1 事件监听

```javascript
事件源.addEventListener('事件类型', 要执行的函数);
```

### 10.2 常见事件类型

| 分类 | 事件 | 触发时机 |
| --- | --- | --- |
| **鼠标事件** | `click` | 鼠标点击 |
| | `mouseenter` | 鼠标移入 |
| | `mouseleave` | 鼠标移出 |
| **键盘事件** | `keydown` | 键盘按下触发 |
| | `keyup` | 键盘抬起触发 |
| **焦点事件** | `focus` | 获得焦点触发 |
| | `blur` | 失去焦点触发 |
| **表单事件** | `input` | 用户输入时触发 |
| | `submit` | 表单提交时触发 |

## 小结

- JS 有两种引入方式：**内部脚本**（`<script>` 写在 `body` 底部）与**外部脚本**（`<script src="">`）。
- JS 是**弱类型语言**：变量可存放不同类型的值，函数形参与返回值无需声明类型。
- 声明变量用 `let`，声明常量用 `const`；早期的 `var` 不严谨，不推荐。
- 基本数据类型包括 `number`、`boolean`、`null`、`undefined`、`string`；字符串推荐单引号，拼接可用**反引号模板字符串**。
- 函数有三种写法：**函数声明**、**函数表达式**、**箭头函数**。
- **JSON** 是 JS 对象标记法书写的文本，key 必须用双引号；`JSON.parse` 与 `JSON.stringify` 负责它与 JS 对象之间的互转。
- 通过 `document.querySelector` / `querySelectorAll` 获取 DOM 对象，再用 `addEventListener` 为**事件源**绑定事件。
